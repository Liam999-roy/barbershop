# Hair Studio

Landing page for a hair salon. I built it to practice HTML, CSS and JavaScript.

**Live site:** https://liam999-roy.github.io/hair-studio/

## What it does

- Banner at the top with the studio name and a short tagline
- Side menu that slides in from the right when you click the menu button
- Services option in the menu that opens a small list (Haircut, Styling, Grooming)
- "Find Out" button that scrolls down to the features section
- "Read More" button that pops up the address and opening hours
- Smooth scrolling when you click any link in the menu

## Built with

- HTML
- CSS
- JavaScript

## Files

```
hair-studio/
  index.html
  style.css

  images/
```

## Running it

Download or clone the project and open `index.html` in your browser. Nothing to install.

```
git clone https://github.com/liam999-roy/hair-studio.git
```
